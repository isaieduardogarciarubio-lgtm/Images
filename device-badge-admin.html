Root Key (Admin)

La root key firma la lista de emisores autorizados. Es UNA sola llave, pero cada admin la desbloquea con SU PROPIA passphrase (como una caja fuerte con varias combinaciones). Si un admin olvida la suya, otro admin activo puede darle una nueva sin rotar la llave ni redesplegar el verificador.

✓ Tienes acceso a la root key.
Este valor NO cambia al agregar/quitar admins — solo cambia si rotas la root key por completo (ver abajo).

Zona de peligro: Rotar Root Key

Solo usa esto si TODOS los admins perdieron su passphrase a la vez, o si sospechas que la root key está comprometida. Esto genera una llave nueva, invalida trusted_issuers actual (hay que volver a aprobar emisores) y requiere actualizar PINNED_ROOT_PUBLIC_KEY_JWK en device-badge-verifier.html y volver a desplegarlo.
